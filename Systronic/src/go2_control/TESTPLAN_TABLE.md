# ตารางเทสหน้างาน · ก๊อปไปใช้ได้เลย

ตัวเลขในคอลัมน์ expect เป็น**การคาดการณ์** จากค่าที่วัดได้ก่อนหน้า ไม่ใช่เกณฑ์ผ่าน
ที่ตกลงกันแล้ว ถ้าได้ไม่ตรงให้จดไว้ ไม่ใช่ถือว่าสอบตก

รายละเอียดวิธีวัดอยู่ใน `MEASURE_TESTCASES.md` ตารางนี้เป็นแผ่นสรุปสำหรับถือหน้างาน

ส่งมอบจริง ทำเรียงตามนี้ ถ้าแถวต้น ๆ ไม่ผ่านอย่าข้ามไปแถวหลัง เพราะจะแยกไม่ออก
